# Ponto Digital — Guia rápido (HTML)

Apresentação sucinta do produto **Ponto Digital Onnibank** para consulta em campo (ex.: Conarh).

- Arquivo: [`index.html`](./index.html)
- Fonte: Manual do Produto — Ponto Digital Onnibank (v3.0)
- Design: tokens do Design System Ringgo

## Como abrir

- **Local:** abra `index.html` no navegador.
- **GitHub Pages:** publique a pasta `apresentacao` (ou o repo) em Pages; a URL tipicamente fica em `/ponto_digital/`.

- Setas ← →, Espaço, swipe no celular
